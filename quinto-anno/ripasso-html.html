Ripasso HTML

Ogni pagina che apri — compresa questa — è un file di testo pieno di tag che il browser traduce in titoli, tabelle, immagini e moduli. Quest'anno costruiremo applicazioni che parlano con un server: prima ripassiamo il linguaggio con cui il server risponde.

Il documento ipertestuale

Un documento ipertestuale è fatto di tre ingredienti distinti:

  • contenuto — testo, immagini, suoni;
  • struttura — l'organizzazione logica in capitoli, paragrafi…;
  • presentazione — le modalità, lo stile, la dimensione…

Come vedremo, HTML si occupa della struttura e CSS della presentazione.

HTML (Hyper Text Markup Language)

HTML è un linguaggio di formato (si dichiara la forma), detto anche linguaggio dichiarativo: si dichiara cosa fare, non come deve essere fatto. Serve per definire la struttura di un documento.

I browser possono essere visti come interpreti delle istruzioni HTML (Microsoft Internet Explorer — oggi Edge —, Mozilla Firefox, Google Chrome…).

⚠️

HTML non è un linguaggio di programmazioneNon ha variabili, cicli o condizioni: descrive solo come è organizzata una pagina. Per questo si parla di linguaggio di markup (di contrassegno).

Editor e piattaforme di sviluppo

Un programma HTML può essere scritto con un qualsiasi editor di testo, perché i comandi sono scritti con comuni caratteri (codici ASCII). Il file dovrà avere estensione .html (o .htm, per le vecchie regole DOS).

Per lo sviluppo è però consigliabile usare delle piattaforme integrate, che permettono di scrivere velocemente il codice e consentono di:

  • evidenziare errori di sintassi;
  • usufruire di una guida in linea;
  • visualizzare il codice scritto;
  • inserire del codice;
  • gestire i colori.
💡

Oggi in laboratorioUn esempio molto diffuso è Visual Studio Code: colora la sintassi, completa i tag e, con un'estensione come Live Server, ricarica la pagina nel browser a ogni salvataggio.

Le applicazioni web: un'architettura a tre livelli

Le applicazioni web sono normalmente descritte come architetture a tre livelli:

  1. il server (servente o host ospitante), che detiene le pagine HTML;
  2. il server web — IIS (Internet Information Server) o, in alternativa, Apache — che gestisce le chiamate alle pagine;
  3. il client, che consulta le pagine con il browser.

Il server, oltre a detenere fisicamente le pagine web, si occupa anche di eseguire le routine che contengono, in modo da inviare al client soltanto la schermata risultante. Così si alleggerisce sia il lavoro del client sia quello dell'infrastruttura di rete (Internet).

I tag

Le istruzioni HTML si esprimono con particolari codici chiamati tag (contrassegni di markup), racchiusi tra parentesi angolari:

HTML
<tag iniziale> ..... </tag finale>

La struttura minima di una pagina

L'istruzione minima per la visualizzazione su un browser è <HTML> … </HTML>; all'interno occorre inserire altre due istruzioni fondamentali, HEAD e BODY:

  • HEAD (intestazione) contiene le informazioni dichiarative, informative o di impostazione, come il titolo;
  • BODY (corpo) contiene l'elemento vero e proprio: testo, immagini e oggetti multimediali da visualizzare.
HTML
<HTML>
   <HEAD>
      <!-- Contenuto dell'elemento HEAD (Intestazione):
           informazioni dichiarative, informative o di impostazione -->
      <TITLE> Pagina di prova </TITLE>
   </HEAD>
   <BODY>
      <!-- Contenuto dell'elemento BODY (Corpo):
           testo, immagini e oggetti multimediali da visualizzare -->
      <P> Paragrafo scritto </P>
   </BODY>
</HTML>

Per rendere il codice più leggibile è buona norma indentare i tag, in modo da rispettare l'ordine gerarchico di appartenenza, anche se non è obbligatorio.

Le parti di codice da commentare vanno scritte tra <!-- e -->:

HTML
<!-- Questa parte è un commento: il browser non la mostra -->

Poiché il linguaggio HTML è in continua evoluzione, un browser che non riconosce un tag lo ignora, senza generare alcun errore.

📌
La stessa pagina, scritta oggi (HTML5)

Gli esempi di questa dispensa usano lo stile classico, con i tag in maiuscolo: il browser li capisce ancora. Nelle pagine nuove si scrive tutto in minuscolo e si aggiungono la dichiarazione <!DOCTYPE html> e la codifica dei caratteri:

HTML
<!DOCTYPE html>
<html lang="it">
  <head>
    <meta charset="utf-8">
    <title>Pagina di prova</title>
  </head>
  <body>
    <p>Paragrafo scritto</p>
  </body>
</html>

CSS — Cascading Style Sheets

I CSS (fogli di stile a cascata) sono anch'essi un linguaggio di formato di tipo dichiarativo: servono a definire lo stile di presentazione di un documento per migliorarne la veste grafica.

I comandi CSS possono essere inseriti:

  • all'interno degli elementi del documento, tra i tag del BODY → fogli di stile in linea;
  • all'interno del documento, nella sezione HEAD (prima di </HEAD>) → fogli di stile incorporati;
  • all'esterno del documento, in un file separato → fogli di stile esterni.
✅

Perché «a cascata»Se più regole colpiscono lo stesso elemento, vince la più vicina: lo stile in linea prevale su quello incorporato, che prevale su quello esterno.

Fogli di stile in linea

Si scrivono nell'attributo STYLE del singolo elemento. Sono consigliati per piccoli ritocchi, perché poco flessibili.

HTML
<HTML>
   <HEAD>
      <TITLE> Esempio </TITLE>
   </HEAD>
   <BODY>
      <P> CIAO </P>

      <P STYLE="Color:RGB(0,0,255); Font-Size:24pt; BACKGROUND:magenta">
         Esempio di paragrafo
      </P>
   </BODY>
</HTML>
  • Color con RGB ha tre parametri fondamentali (Red, Green, Blue) che rappresentano i tre colori di base; ognuno può assumere 256 sfumature (da 0 a 255).
  • Font-Size ha un solo parametro, la dimensione del carattere in punti.

Fogli di stile incorporati

Si scrivono nel tag <STYLE> dentro HEAD. Sono più flessibili di quelli in linea, perché una regola si applica a più oggetti: qui tutti i paragrafi diventano rossi.

HTML
<HTML>
   <HEAD>
      <TITLE> Esempio di stile incorporati </TITLE>
      <STYLE TYPE="TEXT/CSS">
         P {Color:RGB(255,0,0)}
      </STYLE>
   </HEAD>
   <BODY>
      <P> Esempio numero uno </P>
      <P> Esempio numero due </P>
   </BODY>
</HTML>

Tipi di titoli predefiniti

Esistono dei titoli predefiniti, da H1 a H6, usati per evidenziare il livello di importanza dei vari paragrafi (H1 è il più importante).

HTML
<HTML>
   <HEAD>
      <TITLE> Esempio di H1 .. H6 </TITLE>
      <STYLE TYPE="TEXT/CSS">
         H1 {Color:RGB(255,0,0); BACKGROUND:magenta}
         H2 {Color:#B041FF; BACKGROUND:yellow}
         H3 {Color:blue; BACKGROUND:green}
      </STYLE>
   </HEAD>
   <BODY STYLE="BACKGROUND-COLOR:#FFB4F6">
      <H1> Esempio di H1 </H1>
      <H2> Esempio di H2 </H2>
      <H3> Esempio di H3 </H3>
      <H4> Esempio di H4 </H4>
      <H5> Esempio di H5 </H5>
      <H6> Esempio di H6 </H6>
   </BODY>
</HTML>
🎨

Tre modi di scrivere un coloreNell'esempio compaiono tutti: con il codice RGB(255,0,0), con il codice esadecimale #B041FF e con il nome inglese (blue, yellow, magenta…).

Identificazione di classi di elementi

Se all'interno del documento volessimo raggruppare i paragrafi in due o più gruppi, possiamo usare due importanti proprietà degli elementi: ID e CLASS.

ID serve per identificare univocamente un elemento:

HTML
<P ID="primo"> ... </P>
<P ID="secondo"> ... </P>

CLASS serve per far appartenere più elementi di un documento alla stessa classe, così da associare loro una proprietà comune.

HTML
<HTML>
<HEAD>
   <TITLE>... titolo del documento ...</TITLE>
   <STYLE TYPE="text/css">
      PRE.esempio  { background: green }
      PRE.esempio2 { background: yellow }
   </STYLE>
</HEAD>
<BODY>
   <PRE CLASS="esempio" ID="esempio-1">
      <P> CIAO </P>
   </PRE>
   <PRE CLASS="esempio2" ID="esempio-2">
      <P> CIAO </P>
   </PRE>
</BODY>
</HTML>

Il punto nella regola di stile (PRE.esempio) si chiama selettore di classe.

Il carattere *, detto selettore universale, identifica qualsiasi tipo di elemento che appartiene a una determinata classe:

HTML
<HTML>
   <HEAD>
      <TITLE> Esempio di ID CLASS </TITLE>
      <STYLE TYPE="TEXT/CSS">
         *.codice {Color:RGB(255,0,0)}
      </STYLE>
   </HEAD>
   <BODY>
      <P CLASS="codice su P"> Primo P </P>
      <PRE CLASS="codice su PRE"> Primo P </PRE>
   </BODY>
</HTML>
⚠️

Lo spazio separa le classiCLASS="codice su P" non è una classe con il nome lungo: sono tre classi (codice, su, P). Per questo la regola *.codice colpisce sia il paragrafo sia il PRE. Ricorda anche: un ID deve comparire una sola volta nella pagina, una CLASS quante volte vuoi.

Fogli di stile esterni

Finora abbiamo visto comandi HTML e CSS nello stesso file; proviamo adesso a separare la parte HTML dalla parte CSS. La pagina richiama il foglio di stile con il tag <LINK>.

HTML · prova.html
<HTML>
   <HEAD>
      <LINK REL="stylesheet" HREF="esempio.css" TYPE="TEXT/CSS">
   </HEAD>
   <BODY>
      <P CLASS="codice"> Primo P </P>
      <P CLASS="pseudo"> Secondo P </P>
   </BODY>
</HTML>
CSS · esempio.css
P.codice {Color:RGB(255,0,0)}
P.pseudo {Color:RGB(0,0,255)}
💡

Il vantaggio veroUn solo file .css può dare lo stile a tutte le pagine di un sito: per cambiare un colore ovunque basta modificarlo in un punto. È così anche per questo sito.

Sono un elemento molto usato per presentare i dati in modo organizzato.

<HTML>
   <HEAD>
      <TITLE> Esempio di tabella </TITLE>

      </STYLE>
   </HEAD>

      <TABLE BORDER=1>
         <CAPTION> TABELLA DI PROVA </CAPTION>

            <TH> Titolo A </TH>
            <TH> Titolo B </TH>
            <TH> Titolo C </TH>

         </TR>

         </TR>

   </BODY>

Volendo, con il CSS si può modificare l'aspetto della tabella e, con il tag CAPTION, inserire un titolo:

HTML

            <TD> B </TD>
            <TD> C </TD>
         </TR>

            <TD> E </TD>

         </TR>

⚠️

Anche le intestazioni stanno in una rigaLe celle <TH> vanno sempre dentro un <TR>, come le <TD>. La posizione del titolo si sceglie con la proprietà CSS caption-side (top o bottom).

Colspan

In condizioni normali, in una tabella il numero di celle su ogni riga è sempre lo stesso: sarebbe sbagliato definire una riga con 4 celle e un'altra con 3 nella stessa tabella, perché le celle sono incolonnate automaticamente una sotto l'altra su tutte le righe e condividono gli stessi margini. L'attributo colspan permette però di fondere due o più celle della stessa riga. Si consideri la tabella seguente:

HTML
<table style="width: 60%" border="1">
  <tr>
    <td colspan="2">prima e seconda cella</td>
    <td>terza cella</td>
  </tr>
  <tr>
    <td>quarta cella</td>
    <td>quinta cella</td>
    <td>sesta cella</td>
  </tr>
  <tr>
    <td>settima cella</td>
    <td>ottava cella</td>
    <td>nona cella</td>
  </tr>
</table>

che viene visualizzata così:

prima e seconda cellaterza cella
quarta cellaquinta cellasesta cella
settima cellaottava cellanona cella

Rowspan

Con l'attributo rowspan è invece possibile fondere due o più celle della stessa colonna. Si consideri l'esempio seguente:

HTML
<table style="width: 60%" border="1">
  <tr>
    <td rowspan="2">prima e quarta cella</td>
    <td>seconda cella</td>
    <td rowspan="3">terza, sesta e nona cella</td>
  </tr>
  <tr>
    <td>quinta cella</td>
  </tr>
  <tr>
    <td>settima cella</td>
    <td>ottava cella</td>
  </tr>
</table>

che produce nel browser questa visualizzazione:

prima e quarta cellaseconda cellaterza, sesta e nona cella
quinta cella
settima cellaottava cella
🧮

Il trucco per non sbagliareUna cella con rowspan="3" «occupa» il suo posto anche nelle due righe sotto: in quelle righe devi scrivere una <td> in meno. Per questo la seconda riga dell'esempio ha una sola cella.

Un'immagine all'interno di una cella

Una cella può contenere qualsiasi cosa: immagini, elenchi, altro testo. Con border="0" la tabella diventa «nascosta» e serve solo a impaginare.

HTML
<table width="80%" border="0" align="center">

    <td width="50%">
      <img src="../../immagini/problema.gif" alt="" width="38" height="54" />
    </td>
    <td>Esempio di testo inserito in una cella di una tabella nascosta</td>
  </tr>
  <tr>
    <td>
      <ul>
        <li>uno</li>
        <li>due</li>
        <li>tre</li>
      </ul>
    </td>
    <td>
      <img src="../../immagini/soluzione.gif" alt="" width="40" height="61" />
    </td>
  </tr>
</table>

La struttura del testo

Spazi, linee vuote e tabulazioni permettono di presentare meglio un testo. Per farlo useremo:

  • il tag <P> per organizzare il testo in paragrafi;
  • il solo tag di apertura <BR> per andare a capo;
  • il solo tag di apertura <HR> per inserire una riga orizzontale che separa il testo;
  • il tag <PRE> (preformat) per un testo preformattato, mostrato esattamente come è stato scritto, spazi compresi.
HTML
<HTML>
  <BODY>
    <PRE>
                 \|/
                (@ @)
+-------oOO-----(_)------------+
|                              |
|     esempio di utilizzo      |
|            di PRE            |
|                              |
+-----------------oOO----------+
              |__|__|
               || ||
              ooO Ooo
    </PRE>
  </BODY>
</HTML>

Definire un'area

Per definire un'area si usano i tag <DIV> o <SPAN>. Lo stile impostato si riflette su tutti gli elementi contenuti:

HTML
<DIV STYLE="font-size:18px; font-family:arial; color:red">
   Tutto il blocco avrà il colore rosso e carattere Arial
</DIV>
📦

DIV o SPAN?<DIV> è un blocco: va a capo e occupa tutta la larghezza. <SPAN> è in linea: colora o modifica solo un pezzo di frase senza spezzarla.

</BODY>

               <LI> Lazio </LI>
               <LI> Sicilia </LI>
               <LI> Puglia </LI>
            </OL>
         </LI>
         <LI> Francia </LI>

      </UL>
   </BODY>
</HTML>

Ancore e link

I collegamenti ipertestuali (link) sono riferimenti ad altri documenti: il tag che li rappresenta è <A>, l'ancora. I link possono essere:

  • interni al documento HTML;
  • esterni al documento HTML.

Link esterni

Sono collegamenti ad altri documenti HTML o a oggetti multimediali (immagini, suoni, animazioni). Per realizzare un link occorre:

  1. aprire l'ancora con <A>;
  2. specificare con HREF il documento a cui si vuole fare riferimento;
  3. aggiungere il testo da visualizzare per il collegamento;
  4. chiudere l'ancora con </A>.
HTML
<HTML>
   <HEAD>
      <TITLE> Esempio elenchi </TITLE>
      <STYLE TYPE="TEXT/CSS">
         UL {list-style-type:circle}
         OL {list-style-type:upper-roman}
      </STYLE>
   </HEAD>
   <BODY>
      <UL>
         <LI> Italia
            <OL>
               <LI> <A HREF="http://www.istruzione.it"> Ministero dell'Istruzione </A> </LI>
               <LI> <A HREF="http://www.senato.it"> Senato Italiano </A> </LI>
               <LI> <A HREF="http://www.regione.lazio.it"> Regione Lazio </A> </LI>
               <LI> <A HREF="http://www.comune.roma.it"> Comune di Roma </A> </LI>
            </OL>
         </LI>
         <LI> Francia </LI>
         <LI> Germania </LI>
      </UL>
   </BODY>
</HTML>

L'URL identifica univocamente il file all'interno della rete (http://www.comune.roma.it). Se il documento sta nella stessa cartella basta indicare il nome del file HTML, altrimenti va accompagnato dal percorso (path).

⚠️

Collegamenti relativi, non assolutiMentre costruisci il sito non usare percorsi statici (assoluti) come c:\pagine\prova.html: scrivi pagine/prova.html (relativo). Così il sito si può spostare su un'altra macchina o su un server senza rompere i link.

Se non si indica il nome della pagina, il browser cerca sul server index.html, index.htm o default.htm: per questo è buona norma chiamare index.html la prima pagina del sito.

Con le ancore è possibile anche inviare messaggi di posta elettronica dal browser:

HTML
<A HREF="mailto:Indirizzo_email"> Testo da inviare </A>

Link interni

Il link interno è un collegamento a un'altra parte della stessa pagina, usato a volte per orientarsi nei documenti molto lunghi. Il nome di destinazione va definito nello stesso documento con l'attributo NAME o ID:

HTML
<!-- il collegamento -->
<A HREF="#nome"> stringa </A>

<!-- il punto di arrivo, nello stesso documento -->
<A NAME="nome"></A>

Per esempio:

HTML
<A HREF="#bilancio"> Bilancio dello stato </A>
...
...
<A NAME="bilancio"> </A>

Per raggiungere invece un punto preciso all'interno di un'altra pagina si scrive:

HTML
<A HREF="URL#bilancio"> Bilancio dello stato </A>

Due esempi di link con altri attributi: target apre la pagina in una nuova finestra con quel nome, title mostra un suggerimento al passaggio del mouse, e gli eventi onMouseOver/onMouseOut eseguono un piccolo script.

HTML
<a href="default.html" target="Maschera Precedente" name="Precedente"
   title="Maschera Precedente"> Maschera Precedente in nuova maschera</a>

<a href="default.html" name="Precedente"
   onMouseOver="window.status='Maschera Precedente'; return true;"
   onMouseOut="window.status=''; return true;"
   title="Maschera Precedente">Maschera Precedente</a>

Risoluzione e colori

La maggior parte dei computer lavora con queste tre modalità di colore:

  • 256 colori;
  • alta definizione (circa 64.000 colori: 16 bit, cioè 65.536);
  • true color (oltre 16,7 milioni di colori: 24 bit, i 256 × 256 × 256 valori di RGB).

Il true color permette di vedere foto e immagini con maggiore nitidezza, ma a scapito delle elaborazioni che la macchina deve effettuare: ogni programma tende a girare più lentamente.

Nella programmazione HTML i colori si possono definire così:

CSS
COLOR: RGB(0,0,255)   /* codice RGB: Red Green Blue */
COLOR: #FF0000        /* codice esadecimale */

Per esempio, per colorare lo sfondo di rosa (con il CSS) o di blu (con il vecchio attributo BGCOLOR):

HTML
<BODY STYLE="BACKGROUND-COLOR:#FFB4F6">
<BODY BGCOLOR="BLUE">

Le immagini nei documenti HTML

Per inserire un'immagine si usa il tag <IMG>, con l'attributo SRC che indica il file:

HTML
<IMG SRC="images/scuola.gif">

I formati delle immagini dovrebbero essere GIF o JPEG (oggi anche PNG, SVG e WebP) per non incorrere in problemi di compatibilità. In assenza di indicazioni l'immagine viene allineata sulla sinistra dello schermo. Con la proprietà CSS vertical-align si sceglie come il testo vicino si allinea all'immagine:

HTML
<!-- testo allineato al bordo superiore dell'immagine -->
<IMG SRC="images/scuola.gif" STYLE="vertical-align:top"> Testo al top

<!-- testo allineato al bordo inferiore dell'immagine -->
<IMG SRC="images/scuola.gif" STYLE="vertical-align:bottom"> Testo al bottom

<!-- testo allineato al centro dell'immagine -->
<IMG SRC="images/scuola.gif" STYLE="vertical-align:middle"> Testo in mezzo

Per ridimensionare un'immagine si possono usare width e height; il valore è in pixel:

HTML
<IMG SRC="images/scuola.gif" STYLE="width:100px; height:100px">
HTML
<IMG SRC="images/scuola.gif" STYLE="width:30px; height:30px">
⚠️

Rimpicciolire non alleggerisceIl secondo caso è sconsigliato: l'immagine viene scaricata con le dimensioni originali e poi mostrata ridotta. Meglio ridurla prima con un programma di elaborazione delle immagini. Aggiungi sempre anche l'attributo alt: è il testo che legge chi non vede l'immagine.

Le mappe sensibili

Una mappa sensibile (o cliccabile) è un'immagine con delle aree selezionabili con il tasto sinistro del mouse. Queste aree, dette hot-spot (punti caldi), contengono collegamenti ad altri documenti. Ne esistono due tipi:

  • gestite dal server (server-side): al clic vengono inviate al server le coordinate del punto selezionato insieme al nome della mappa; un apposito programma sul server identifica il documento e lo invia al client;
  • gestite dal client (client-side): la mappa è definita dentro il documento HTML, che contiene tutte le informazioni necessarie per gestire i collegamenti.

Le mappe gestite dal client

Si definiscono con gli elementi MAP e AREA:

HTML
<IMG SRC="image/animali.gif" USEMAP="#mappa1">
<MAP NAME="mappa1">
   <AREA SHAPE="RECT" COORDS="0,0,146,84"     HREF="farfalla.html">
   <AREA SHAPE="RECT" COORDS="148,0,297,84"   HREF="pavone.html">
   <AREA SHAPE="RECT" COORDS="0,86,146,180"   HREF="fenicottero.html">
   <AREA SHAPE="RECT" COORDS="148,86,297,180" HREF="cerbiatto.html">
</MAP>
AttributoA cosa serve
USEMAPindica al browser che si tratta di una mappa client-side e qual è
SHAPEla forma dell'area: RECT, CIRCLE, POLY
COORDSle coordinate dell'hot-spot (per RECT: x1,y1 in alto a sinistra e x2,y2 in basso a destra)
HREFil collegamento all'URL desiderato

I frame

In un documento HTML è possibile suddividere la finestra del browser in più parti, dette frame; ogni frame può essere gestito indipendentemente dagli altri. L'organizzazione della pagina si definisce con FRAMESET: gli attributi ROWS e COLS stabiliscono numero e ampiezza dei frame, in percentuale oppure in pixel.

HTML
<FRAMESET ROWS="200,*">

Il numero senza percentuale indica i pixel, mentre l'asterisco indica che lo spazio restante va al frame della seconda riga. Ogni frame si definisce con <FRAME>, indicando la pagina da caricare:

HTML
<FRAMESET COLS="50%,50%">
   <FRAMESET ROWS="50%,50%">
      <FRAME SRC="casella1.html">
      <FRAME SRC="casella2.html">
   </FRAMESET>
   <FRAMESET ROWS="33%,33%,33%">
      <FRAME SRC="casella3.html">
      <FRAME SRC="casella4.html">
      <FRAME SRC="casella5.html">
   </FRAMESET>
</FRAMESET>

Queste istruzioni dividono la pagina prima in due colonne, poi la prima colonna in due righe e la seconda in tre righe:

Ai frame si possono associare i seguenti attributi:

AttributoEffetto
FRAMEBORDER="YES | NO"mostra o nasconde il bordo del frame
BORDERCOLOR="#rrggbb"modifica il colore del bordo
BORDER=nmodifica la dimensione del bordo
MARGINWIDTHmargine orizzontale, in pixel, tra il bordo e il contenuto del frame
MARGINHEIGHTmargine verticale, in pixel, tra il bordo e il contenuto del frame
SCROLLINGcontrolla le barre di scorrimento nel frame: YES, NO, AUTO
NORESIZEimpedisce all'utente di ridimensionare il frame
⚠️
FRAMESET non esiste più in HTML5

I browser moderni lo mostrano ancora solo per compatibilità: per questo non c'è il bottone ▶ Prova. Oggi la suddivisione della pagina si fa con il CSS (flexbox, grid) e, per incorporare un'altra pagina dentro la propria, si usa <iframe> — come fa l'editor dal vivo di questa dispensa:

HTML
<iframe src="casella1.html" width="100%" height="300"
        title="Pagina incorporata"></iframe>

Moduli o form

I form (moduli) sono contenitori di elementi HTML che permettono di realizzare un'interfaccia grafica con cui l'utente interagisce, inserendo o visualizzando le informazioni richieste. Lo sviluppo prevede:

  1. la creazione del form con i suoi elementi, per prendere i dati in input;
  2. l'elaborazione di queste informazioni, che può avvenire direttamente sul client con programmi di scripting, oppure sul server: le coppie nome=valore dei campi, separate dal carattere &, vengono inviate al programma di scripting presente sul server.

Il form si definisce con i tag <FORM> … </FORM>, che non possono essere nidificati (un form non può stare dentro un altro). La sintassi è:

HTML
<FORM [ACTION="URL_dello_script"] [METHOD="GET|POST"]>
   Elementi HTML
</FORM>
  • ACTION contiene l'URL del programma che elabora i dati, oppure un indirizzo e-mail.
  • METHOD specifica la modalità di trasferimento delle informazioni (se non indicato, GET per default).
GETPOST
Dove vanno i datiaggiunti all'URL dello script, dopo un ?inviati allo script come flusso informativo separato
Sul serverseparati in due variabili: SCRIPT_NAME (la parte con l'URL) e QUERY_STRING (la parte dati)il server legge i dati dal corpo della richiesta
Quantitàlimitata: storicamente 255 caratteri per l'URLil server può leggere una quantità indefinita di informazioni
🔒

GET si vede, POST noCon GET i dati finiscono nella barra degli indirizzi e nella cronologia (es. login.php?utente=Paolo&pwd=1234): mai usarlo per le password. Oggi i browser accettano URL molto più lunghi di 255 caratteri, ma per dati grandi o riservati si usa sempre POST.

L'elemento INPUT

Uno degli elementi di un form è INPUT:

HTML
<INPUT TYPE="Tipo Elemento" NAME="Nome Elemento" VALUE="Valore Iniziale">
  • NAME identifica il nome dell'elemento;
  • VALUE assegna un valore iniziale, presentato al caricamento della pagina;
  • TYPE identifica il tipo di elemento.

Il campo di testo

È un elemento grafico formato da una singola riga, in cui l'utente può scrivere una stringa:

HTML
<INPUT TYPE="TEXT" NAME="Nome Campo" SIZE=Larghezza VALUE="Valore" MAXLENGTH=Lunghezza>
  • NAME assegna un nome al campo;
  • SIZE definisce la dimensione del campo (per default 20 caratteri);
  • VALUE assegna un valore iniziale;
  • MAXLENGTH fissa la lunghezza massima; se è maggiore di SIZE, il testo scorre automaticamente dentro il campo.
HTML
<INPUT TYPE="TEXT" NAME="Utente" SIZE=30 VALUE="Inserisci il nome">

Il campo PASSWORD

Se a TYPE si assegna PASSWORD, il campo non mostra il contenuto digitato:

HTML
<INPUT TYPE="PASSWORD" NAME="Utente" SIZE=8>

I campi nascosti

Sono normali campi non visualizzati, usati come appoggio per passare informazioni agli script:

HTML
<INPUT TYPE="HIDDEN" NAME="Utente" VALUE="Paolo">

Il campo TEXTAREA

Permette di inserire più righe di testo; ROWS e COLS sono il numero di righe e di colonne dell'area:

HTML
<TEXTAREA NAME="utente" ROWS=NumeroRighe COLS=NumeroColonne>
   Contenuto Iniziale
</TEXTAREA>

Le caselle di controllo

Le caselle di controllo (checkbox) memorizzano informazioni di tipo sì/no, vero/falso (booleane). Normalmente valgono false; se l'utente le seleziona valgono true. Per impostarle già selezionate si usa l'attributo CHECKED:

HTML
Roma<INPUT TYPE="CHECKBOX" NAME="C1" CHECKED>
Milano<INPUT TYPE="CHECKBOX" NAME="C2">
Torino<INPUT TYPE="CHECKBOX" NAME="C3" CHECKED>

Le caselle di scelta alternativa

I radio button sono simili alle caselle di controllo, ma se ne può selezionare soltanto uno per gruppo. Il gruppo è formato dai pulsanti con lo stesso NAME:

HTML

Milano<INPUT TYPE="RADIO" NAME="R">
Torino<INPUT TYPE="RADIO" NAME="R" CHECKED>

Permettono di scegliere un dato da una lista (elenco a discesa):

HTML
<SELECT NAME="Nome Select" SIZE=NumeroRighe [MULTIPLE]>

   <OPTION VALUE="Nome2" [SELECTED]> Stringa2

</SELECT>

I pulsanti

Il pulsante generico va associato a uno script; VALUE è la scritta che compare sopra:

HTML
<INPUT TYPE="BUTTON" NAME="B1" VALUE="CALCOLA">

Con TYPE="SUBMIT" si ottiene un pulsante che, premuto, invia al server il contenuto di tutti gli elementi del form:

HTML
<INPUT TYPE="SUBMIT" VALUE="Invia">

Per ripristinare i valori del form allo stato originale si usa:

HTML
<INPUT TYPE="RESET" VALUE="Annulla i dati immessi">

Da ricordare

  • HTML definisce la struttura della pagina, CSS la presentazione: sono due linguaggi dichiarativi, non di programmazione.
  • Una pagina ha sempre <HTML>, <HEAD> (informazioni, titolo) e <BODY> (ciò che si vede); un tag sconosciuto viene ignorato senza errori.
  • Il CSS può essere in linea (STYLE=), incorporato (<STYLE> nella HEAD) o esterno (<LINK> a un file .css); ID è unico, CLASS si ripete.
  • Tabelle: TABLE → TR (righe) → TD/TH (celle); colspan unisce celle della stessa riga, rowspan della stessa colonna.
  • I link si fanno con <A HREF="…">: esterni (URL), interni (#nome), e-mail (mailto:); usa sempre percorsi relativi e chiama index.html la prima pagina.
  • Le immagini: <IMG SRC="…" alt="…">; ridimensionarle con width/height non le rende più leggere.
  • Nei form ACTION dice dove inviare i dati, METHOD come: GET li mette nell'URL, POST in un flusso separato.
  • Ogni campo ha un NAME: i dati arrivano al server come coppie nome=valore separate da &.
