Le strutture condizionali

Dispensa 2 · Valori booleani, if / elif / else, operatori logici.

Dispensa 2 Lettura 15 min Tipo Laboratorio

In questa dispensa

1. Dalla sequenza alla scelta

Finora i nostri programmi eseguivano le istruzioni una dopo l'altra, sempre nello stesso ordine. Con le strutture condizionali un programma può invece scegliere quali istruzioni eseguire in base ai dati: è ciò che gli permette di reagire a situazioni diverse. Per scegliere servono due ingredienti: le condizioni (domande a cui si risponde Vero o Falso) e l'istruzione if che le usa.

2. Valori booleani e confronti

Un confronto produce un valore di tipo bool, che può essere solo True o False.

Python
print(5 > 3)         # True
print(5 == 3)        # False
print(5 != 3)        # True
print(type(True))    # <class 'bool'>
OperatoreSignificatoEsempioRisultato
==Uguale a3 == 3True
!=Diverso da3 != 4True
< <=Minore, minore o uguale2 < 2False
> >=Maggiore, maggiore o uguale2 >= 2True
  • True e False hanno l'iniziale maiuscola: scrivere true provoca un NameError.
  • = assegna, == confronta. Scrivere if x = 5: è un errore di sintassi (in C compilerebbe, con effetti disastrosi).
  • Confronti concatenati: si può scrivere 0 <= x < 10, che equivale a 0 <= x and x < 10. In C bisognerebbe usare &&.
  • Le stringhe si confrontano con == (niente equals come in Java), ma maiuscole e minuscole contano: "Ciao" == "ciao" è False. Si aggira con "Ciao".lower() == "ciao".
⚠️
Non confrontare con == i risultati di calcoli decimali

I numeri float sono rappresentati in modo approssimato:

Python
print(0.1 + 0.2)           # 0.30000000000000004
print(0.1 + 0.2 == 0.3)    # False

3. L'istruzione if / else

🪧

Un'analogia: il bivioImmagina il programma come un viaggiatore che cammina lungo una strada. L'if è un cartello al bivio: "se piove prendi la strada coperta, altrimenti quella panoramica". Si sceglie una sola delle due strade; poi i percorsi si riuniscono e il viaggio prosegue con le istruzioni successive.

eta = int(input("Età: "))
if eta >= 18:
    print("Maggiorenne")
else:
    print("Minorenne")

Il blocco e l'indentazione

  • Dopo la condizione ci sono sempre i due punti :.
  • Tutte le righe del blocco hanno lo stesso rientro (4 spazi). Il blocco finisce quando il rientro torna al livello precedente.
  • Un blocco non può essere vuoto: se vuoi lasciarlo da completare scrivi pass.
⚠️
Gli errori di indentazione
Python

print("Maggiorenne")       # IndentationError: expected an indented block
Python
if eta >= 18:
    print("Maggiorenne")
  print("ok")               # IndentationError: unindent does not match

Non mischiare mai tab e spazi nello stesso file.

4. La catena if / elif / else

Quando le alternative sono più di due si usa elif (contrazione di "else if"), tante volte quante servono. else è facoltativo e, se c'è, sta sempre in fondo.

La catena passo per passo
Python
voto = float(input("Voto: "))if voto >= 9:    giudizio = "Ottimo"elif voto >= 7:    giudizio = "Buono"elif voto >= 6:    giudizio = "Sufficiente"else:    giudizio = "Insufficiente"print("Giudizio:", giudizio)

7.5
  • Le condizioni vengono valutate dall'alto verso il basso e si esegue solo il primo ramo vero: gli altri vengono saltati.
  • Quindi l'ordine conta. Se mettessi per prima voto >= 6, un 9 verrebbe giudicato "Sufficiente".
  • Grazie all'ordine, in ogni elif si sa già che le condizioni precedenti erano false: per questo elif voto >= 7 non ha bisogno di scrivere anche voto < 9.

Catena o if separati?

Catena
x = 4

# catena: si esegue al massimo UN ramo
if x > 2:
    print("maggiore di 2")
elif x > 3:
    print("maggiore di 3")     # non viene raggiunto: il primo ramo è già vero
if separati
x = 4

if x > 2:
    print("maggiore di 2")
if x > 3:
    print("maggiore di 3")     # stampato: decisioni indipendenti

5. Operatori logici: and, or, not

🕴️

Un'analogia: il buttafuoriUna discoteca ha regole d'ingresso. Con and devi rispettare tutte le regole (sei maggiorenne e sei in lista). Con or ne basta una (sei in lista o conosci il proprietario). Con not la regola si capovolge (non sei stato bandito).

Python
eta = int(input("Età: "))
if eta >= 18 and eta < 65:        # equivale a: 18 <= eta < 65
    print("Tariffa intera")
elif eta < 18 or eta >= 65:
    print("Tariffa ridotta")

Un esempio più ricco: un anno è bisestile se è divisibile per 4 ma non per 100, oppure se è divisibile per 400.

Python
anno = int(input("Anno: "))
if (anno % 4 == 0 and anno % 100 != 0) or anno % 400 == 0:
    print("Bisestile")
else:
    print("Non bisestile")
  • Precedenza: i confronti si valutano prima, poi not, poi and, poi or. Nel dubbio usa le parentesi: rendono il codice più chiaro.
  • Corto circuito: and e or si fermano appena il risultato è noto. Per questo if b != 0 and a / b > 2: non divide mai per zero.
⚠️
Un errore classico: x == 1 or 2

if x == 1 or 2: non significa "x vale 1 oppure 2". Python lo legge come (x == 1) or 2 e il valore 2 conta sempre come "vero": la condizione è sempre vera, senza alcun messaggio di errore. Ogni confronto va scritto per intero:

Python
if x == 1 or x == 2:       # corretto
if x in (1, 2):            # corretto e più breve

6. Altri strumenti utili

L'operatore in

Verifica l'appartenenza: a una stringa (già visto) oppure a un elenco di valori tra parentesi. Il contrario è not in.

Python
if "a" in parola:
    print("Contiene la a")

if mese in (4, 6, 9, 11):
    print("Il mese ha 30 giorni")

if scelta not in (1, 2, 3):
    print("Scelta non valida")

Quando un valore conta come "vero" o "falso"

In una condizione, ogni valore può essere interpretato come vero o falso. Sono considerati falsi: 0, 0.0, la stringa vuota "" e False. Tutti gli altri valori sono veri.

Python
nome = input("Nome: ")
if not nome:                       # vero se l'utente ha premuto solo Invio
    print("Non hai scritto niente")

Espressione condizionale su una riga

Corrisponde all'operatore ? : del C: condizione ? a : b diventa a if condizione else b.

Python
n = int(input("Numero: "))
tipo = "pari" if n % 2 == 0 else "dispari"
print(n, "è", tipo)

Condizioni annidate

Un if può contenere altri if: basta aggiungere un livello di indentazione.

Python
eta = int(input("Età: "))
if eta >= 18:
    if eta >= 65:
        print("Maggiorenne, over 65")
    else:
        print("Maggiorenne")
else:
    print("Minorenne")

Non esagerare: oltre due o tre livelli il codice diventa illeggibile. Spesso si può semplificare con and oppure con una catena elif.

Gli errori che Python non segnala

Sono i più insidiosi: il programma gira, ma sbaglia. Controlla sempre di non averne commessi.

  • Input non convertito: input() == 5 è sempre False, perché la stringa "5" non è mai uguale al numero 5. Converti subito con int() o float().
  • Il falso "o": x == 1 or 2 è sempre vero.
  • Rami nell'ordine sbagliato in una catena elif.
  • Confini sbagliati: > al posto di >= (o viceversa).
🧪

Come si collauda un programma con le condizioniProva almeno un caso per ogni ramo e poi i valori di confine. Per un biglietto con fasce 6 e 18 anni, ad esempio, prova 5, 6, 17 e 18: è lì che si nascondono quasi tutti gli errori.

8. Riepilogo

  • I confronti producono bool: True e False (con la maiuscola). = assegna, == confronta.
  • if, elif, else terminano con : e il loro blocco è delimitato dall'indentazione (4 spazi).
  • In una catena si esegue solo il primo ramo vero: l'ordine delle condizioni è importante.
  • Operatori logici: and, or, not (non &&, ||, !). Precedenza: confronti, not, and, or.
  • Ogni confronto per intero: x == 1 or x == 2, oppure x in (1, 2).
  • Converti sempre l'input prima di confrontarlo con un numero.
  • Collauda i programmi con un caso per ogni ramo e con i valori di confine.
