1. Che cos'è Python

Python è un linguaggio di programmazione ad alto livello, interpretato e a tipizzazione dinamica, nato all'inizio degli anni '90 per opera di Guido van Rossum. La sua sintassi è volutamente compatta e leggibile: a parità di problema, un programma Python è in genere molto più corto dell'equivalente in C o Java. Si usa in moltissimi ambiti: automazione e scripting, analisi dei dati, intelligenza artificiale, sviluppo web, didattica.

Come si esegue un programma

  • Shell interattiva (il prompt >>>): scrivi un'istruzione e ottieni subito il risultato. Ottima per fare prove.
  • File .py: scrivi il programma in un editor e lo esegui con python nomefile.py oppure dal pulsante "Run" del tuo ambiente.
  • Ambienti consigliati: Thonny e IDLE (semplici), VS Code (più completo).

2. Sintassi di base

Python
# Questo è un commento: Python lo ignora
print("Ciao, mondo!")   # commento a fine riga
  • Niente punto e virgola: ogni istruzione sta su una riga.
  • Commenti con il simbolo # (fino a fine riga).
  • Maiuscole e minuscole contano: totale e Totale sono due variabili diverse, e Print non è print.
  • Nomi delle variabili: lettere, cifre e underscore _, ma non possono iniziare con una cifra né coincidere con parole riservate (if, for, while, class ...). Per convenzione si usa lo stile snake_case: somma_totale, voto_medio.
⚠️
Attenzione all'indentazione

In Python i blocchi di codice si riconoscono dal rientro delle righe. Quando incontreremo if e cicli, sarà fondamentale. Per ora ricorda una regola: una riga normale non deve avere spazi all'inizio. Questo programma dà errore:

Python
x = 5
  y = 6        # IndentationError: unexpected indent

Quando indenti usa sempre 4 spazi (la maggior parte degli editor lo fa premendo Tab).

3. Il comando print

print() mostra a schermo uno o più valori. Puoi passargli argomenti di tipo diverso separati da virgola: non servono specificatori di formato come %d del C.

Python
print("Ciao")                    # Ciao
print("Somma:", 3 + 4)           # Somma: 7
print("a", "b", "c", sep="-")    # a-b-c
print("Senza a capo", end="")    # non va a capo
print()                          # stampa una riga vuota
  • Tra gli argomenti print inserisce uno spazio. Si cambia con il parametro sep.
  • Alla fine print va a capo. Si cambia con il parametro end.
  • Le stringhe possono stare tra apici doppi "..." o singoli '...': sono equivalenti.

🏷️
Un'analogia: scatole contro etichette

In C una variabile è una scatola con sopra scritto il tipo: int x; è una scatola fatta apposta per contenere un intero, e ci metti dentro il valore.

In Python è l'opposto: i valori sono oggetti che esistono per conto loro, e la variabile è un'etichetta adesiva che ci attacchi sopra. L'etichetta si può staccare e riattaccare a un oggetto di tipo diverso:

Python
x = 5          # l'etichetta x è attaccata all'intero 5
x = "ciao"     # ora x è attaccata a una stringa: nessun errore

Il tipo non si dichiara: è il valore ad averlo. Per scoprirlo si usa type():

Python
print(type(16))         # <class 'int'>
print(type(1.75))       # <class 'float'>

Assegnazione multipla e scambio

Python
a, b = 3, 7          # a vale 3, b vale 7
a, b = b, a          # scambio: ora a vale 7 e b vale 3

In C serve una variabile temporanea; in Python lo scambio si fa in una sola riga.

Conversioni di tipo

Python
int("12")      # 12      da stringa a intero
float("3.5")   # 3.5     da stringa a decimale
str(10)        # "10"    da numero a stringa
int(3.9)       # 3       il decimale viene troncato, non arrotondato

5. Operazioni sui numeri

OperatoreSignificatoEsempioRisultato
+ - *Somma, differenza, prodotto7 * 321
/Divisione (il risultato è sempre un float)7 / 23.5
//Divisione intera7 // 23
%Resto della divisione7 % 21
**Potenza2 ** 101024
  • Precedenza: prima **, poi * / // %, infine + -. Le parentesi hanno sempre la precedenza più alta.
  • Operatori composti: +=, -=, *=, /= ... ad esempio x += 1 equivale a x = x + 1. Non esistono ++ e --.
  • Funzioni utili: abs(x) valore assoluto, round(x, n) arrotonda a n decimali, min(a, b) e max(a, b).
📌
Due differenze importanti rispetto a C e Java
  1. La divisione / restituisce sempre un float: 4 / 2 vale 2.0, non 2. Per la divisione intera usa //.
  2. Gli interi non hanno limite di grandezza: 2 ** 100 vale 1267650600228229401496703205376, senza overflow.
Python
base = 5
altezza = 3
area = base * altezza / 2
print("Area del triangolo:", area)    # Area del triangolo: 7.5

Le f-string: il modo migliore per comporre testo

Mettendo una f davanti alla stringa, ciò che sta tra graffe viene sostituito con il valore dell'espressione.

Python
nome = "Luca"
eta = 16
print(f"{nome} ha {eta} anni")              # Luca ha 16 anni
print(f"Tra 5 anni avrà {eta + 5} anni")     # Tra 5 anni avrà 21 anni
print(f"Pi greco: {3.14159:.2f}")            # Pi greco: 3.14
FormatoEffettoEsempio
:.2fNumero con 2 decimalif"{3.14159:.2f}" → 3.14
:02dIntero su 2 cifre, con zero inizialef"{7:02d}" → 07
:>8Allinea a destra in 8 caratterif"{42:>8}" → 42
⚠️

Non si concatenano stringhe e numeri"Età: " + 16 dà TypeError. Hai due soluzioni: convertire con str(16) oppure (meglio) usare una f-string: f"Età: {16}".

7. Leggere dati con input

Python
nome = input("Come ti chiami? ")
print("Ciao", nome)

Il testo tra parentesi è il messaggio mostrato all'utente. Il programma si ferma e attende che venga premuto Invio.

⌨️
input restituisce sempre una stringa

Anche se scrivi un numero, Python lo riceve come testo. Questo programma stampa 34 invece di 7:

Python
a = input("Primo numero: ")      # l'utente scrive 3
b = input("Secondo numero: ")    # l'utente scrive 4
print(a + b)                     # 34   (concatenazione di stringhe!)

Bisogna convertire subito il valore letto:

Python
a = int(input("Primo numero: "))
b = int(input("Secondo numero: "))
print("Somma:", a + b)           # Somma: 7

Per numeri con la virgola usa float(input(...)). Se l'utente scrive un testo non numerico, Python segnala ValueError: imparerai a gestirlo più avanti.

9. Riepilogo

  • Niente ;, niente graffe: conta la fine riga e l'indentazione.
  • Le variabili sono etichette attaccate ai valori; il tipo appartiene al valore e si controlla con type().
  • / dà sempre un float; per la divisione intera usa //, per il resto %, per la potenza **.
  • Le stringhe si indicizzano da 0, si affettano con [inizio:fine] e sono immutabili.
  • Per comporre testo usa le f-string: f"{x:.2f}".
  • input() restituisce sempre una stringa: converti con int() o float().
  • Di fronte a un errore leggi l'ultima riga del messaggio.
