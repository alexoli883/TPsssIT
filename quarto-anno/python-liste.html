Finora ogni variabile conteneva un solo valore. Ma se dobbiamo memorizzare i voti di 30 studenti, non possiamo creare 30 variabili con nomi diversi. Serve una variabile che contenga tanti valori: in Python questo ruolo lo svolge la lista (list).

2. Creare una lista

Una lista si scrive con le parentesi quadre [ ], mettendo gli elementi uno dopo l'altro separati da virgole. Gli elementi possono essere di qualunque tipo: numeri, stringhe, booleani, e anche tipi diversi nella stessa lista. Il nome della lista, come per ogni variabile, è scelto da noi: conviene un nome al plurale (voti, nomi) perché contiene più valori.

Python
voti = [6, 8, 7, 9]
nomi = ["Anna", "Luca", "Sara"]
mista = [1, "ciao", 3.5, True]
vuota = []
print(voti)
print(mista)
print(len(nomi), len(vuota))

Output

python
[6, 8, 7, 9]
[1, 'ciao', 3.5, True]
3 0

Guardando l'output si nota che print mostra la lista intera, con le parentesi quadre e le virgole; le stringhe compaiono tra apici. Una lista può anche essere vuota ([]): sembra inutile, ma è il punto di partenza ideale quando i dati arrivano a poco a poco, per esempio dalla tastiera.

2.1 Gli elementi possono essere variabili ed espressioni

Dentro le parentesi si può scrivere qualsiasi espressione: Python la calcola in quel momento e mette nella lista il valore ottenuto. La lista non "ricorda" l'espressione né la variabile: se in seguito x cambia, la lista resta com'è.

Python
x = 5
voti = [6, x, x * 2, x + 1]
print(voti)
x = 100
print(voti)

Output

python
[6, 5, 10, 6]
[6, 5, 10, 6]

Come si vede, dopo x = 100 la lista è identica: dentro c'è il valore 5, non il collegamento alla variabile x.

2.2 Crearla da altre sequenze

Spesso una lista non si scrive a mano ma si ricava da qualcosa che già esiste. La funzione list() trasforma una sequenza (un range, una stringa) in una lista; l'operatore * ripete un elemento e serve a creare una lista di n valori uguali, per esempio per partire da una serie di contatori a zero.

Python
print(list(range(5)))
print(list("ciao"))
print([0] * 5)

Output

python
[0, 1, 2, 3, 4]
['c', 'i', 'a', 'o']
[0, 0, 0, 0, 0]

Il range è quello della lezione 3 e accetta gli stessi tre argomenti (inizio, fine escluso, passo):

Python

Output

Con input() si legge un valore alla volta, quindi per riempire una lista si parte da una lista vuota o da un primo elemento e si aggiungono i valori con append (descritto meglio nella sezione 5). Ricorda che input restituisce sempre una stringa: se servono numeri bisogna convertire.

Una lista è una sequenza ordinata di valori: l'ordine in cui li scrivi è quello in cui restano.

Il suo nome è uno solo, i valori sono tanti: per distinguerli si usa la loro posizione (indice), come spiegato ora.

3. Indici e fette

3.1 L'indice: il numero dell'armadietto

Ogni elemento ha una posizione, detta indice, che parte da 0 (come in C e Java e come per le stringhe della lezione 1). Il primo elemento ha indice 0, il secondo 1 e così via: in una lista di 5 elementi gli indici validi sono 0, 1, 2, 3, 4. Si scrive il nome della lista seguito dall'indice tra parentesi quadre: l[2] significa "l'elemento in posizione 2 della lista l".

Python permette anche gli indici negativi, che contano dalla fine: -1 è l'ultimo elemento, -2 il penultimo, ecc. Sono comodissimi perché non occorre sapere quanto è lunga la lista per arrivare all'ultimo elemento. Ecco la lista l = [10, 20, 30, 40, 50] con i due tipi di indice:

l[0]l[1]l[2]l[3]l[4]
Valore1020304050
Indice positivo01234
Indice negativo-5-4-3-2-1
Python
l = [10, 20, 30, 40, 50]
print(l[0], l[4])
print(l[-1], l[-5])
print(l[2])
print(l[-2])

Output

python
10 50
50 10
30
40

Le quattro righe di output corrispondono alle quattro print: l[0] e l[4] sono primo e ultimo; l[-1] e l[-5] sono ancora ultimo e primo, scritti dalla parte della fine; poi l[2] (30) e l[-2] (il penultimo, 40).

⚠️

Attenzione: IndexErrorIn una lista di 5 elementi l'indice più alto è 4, non 5. Chiedere un indice che non esiste provoca l'errore IndexError: list index out of range. In generale, in una lista di n elementi gli indici validi vanno da 0 a n - 1 (e da -n a -1). L'ultimo elemento si ottiene sempre con l[-1] oppure l[len(l) - 1].

3.2 Le fette: ritagliare un pezzo di lista

Una fetta (in inglese "slice") è un pezzo di lista consecutivo. Si scrive l[inizio:fine]: comprende gli elementi dall'indice inizio fino a fine - 1, cioè l'indice finale è escluso. Come nella lezione 1: pensa alle posizioni come a "tagli" tra un elemento e l'altro; l[1:4] prende ciò che sta tra il taglio 1 e il taglio 4.

Si possono omettere i limiti: se manca l'inizio si parte dal primo elemento, se manca la fine si arriva all'ultimo. Un terzo numero opzionale è il passo: l[inizio:fine:passo]. Con passo negativo si percorre la lista all'indietro.

Python
l = [10, 20, 30, 40, 50]
print(l[1:4])
print(l[:3])
print(l[3:])
print(l[:])
print(l[::2])
print(l[-2:])
print(l[2:100])

Output

4. Le liste sono modificabili

Una caratteristica fondamentale delle liste è che sono mutabili: dopo averle create, possiamo cambiare i valori dei loro elementi senza ricreare la lista. Si assegna un nuovo valore all'indice desiderato, esattamente come si farebbe con una variabile: lista[indice] = nuovo_valore. L'elemento vecchio viene sostituito, tutti gli altri restano dove sono.

💡

Un'analogia: la lavagna e il foglio stampatoUna stringa è come un testo stampato: per correggere una lettera devi stampare un foglio nuovo. Una lista è come una lavagna: puoi cancellare un solo riquadro e riscriverlo, e il resto non si tocca. Per questo si dice che le stringhe sono immutabili e le liste mutabili.

Vediamo l'evoluzione di una lista passo dopo passo. Ogni print mostra com'è la lista in quel momento:

Python
voti = [6, 8, 7]
print(voti)
voti[1] = voti[1] + 1
print(voti)
voti[2] += 2
print(voti)
voti[0] = "assente"
print(voti)

Output

python
[6, 8, 7]
[6, 9, 7]
[6, 9, 9]
['assente', 9, 9]
IstruzioneChe cosa faLista dopo
voti = [6, 8, 7]crea la lista[6, 8, 7]
voti[1] = voti[1] + 1legge l'elemento in posizione 1 (8), calcola 9 e lo riscrive nella stessa posizione[6, 9, 7]
voti[2] += 2forma abbreviata di voti[2] = voti[2] + 2[6, 9, 9]
voti[0] = "assente"sostituisce con un valore di tipo diverso: permesso, le liste non impongono un tipo['assente', 9, 9]

Si noti che l'indice può comparire sia a destra sia a sinistra del segno =: a destra significa "leggi quell'elemento", a sinistra "scrivi in quella posizione".

4.1 Modificare tutti gli elementi: serve l'indice

Se vogliamo cambiare ogni elemento (per esempio aumentare di 1 tutti i voti) il ciclo deve conoscere la posizione, quindi si usa range(len(lista)):

Python
voti = [5, 6, 4]
for i in range(len(voti)):
    voti[i] = voti[i] + 1
print(voti)

Output

python
[6, 7, 5]

Attenzione alla tentazione di scorrere direttamente gli elementi. Nel programma seguente la variabile v è soltanto una copia temporanea del valore dell'elemento: assegnare un nuovo valore a v non cambia la lista.

Python
voti = [5, 6, 4]
for v in voti:
    v = v + 1
print(voti)

Output

python
[5, 6, 4]
⚠️

Le stringhe invece noCon una stringa, s[0] = "C" non è consentito e dà l'errore TypeError: 'str' object does not support item assignment. Per "modificare" una stringa se ne costruisce una nuova (con fette e concatenazione). Le liste si cambiano sul posto; le stringhe no.

Oltre a sostituire un valore, una lista può anche crescere e rimpicciolirsi: aggiungere o togliere elementi. Di questo parliamo nella sezione 5.

5. Operazioni e metodi

Una volta creata, una lista si può interrogare (quanti elementi ha? c'è il 7? qual è il massimo?) e modificare (aggiungere, togliere, riordinare). Le due famiglie di operazioni si comportano in modo molto diverso e confonderle è la causa del maggior numero di errori sulle liste:

  • le operazioni che leggono calcolano un risultato e lasciano la lista com'è: il risultato va usato (stampato o salvato in una variabile);
  • i metodi che modificano cambiano la lista sul posto e non restituiscono nulla: non c'è niente da salvare.

Un metodo è una funzione che appartiene a un oggetto e si chiama con il punto: lista.append(5) si legge "alla lista, aggiungi 5". Le funzioni normali come len(lista) o sum(lista) invece ricevono la lista come argomento.

5.1 Leggere la lista senza modificarla

Python
l = [4, 7, 2, 7]
print(len(l))
print(sum(l))
print(min(l), max(l))
print(l.count(7))
print(l.index(7))
print(l)

5.2 Modificare la lista: aggiungere

La lista può crescere. append(x) aggiunge un elemento in fondo (è il metodo più usato in assoluto). Se l'argomento è una lista, viene aggiunta come un unico elemento (una lista dentro la lista), come mostrano la seconda stampa e la len:

Python
l = [4, 7, 2]
l.append(9)
print(l)
l.append([1, 2])
print(l)
print(len(l))

Output

python
[4, 7, 2, 9]
[4, 7, 2, 9, [1, 2]]
5

Per aggiungere in fondo tutti gli elementi di un'altra lista si usa extend; per inserire in una posizione precisa si usa insert(posizione, valore): gli elementi da quella posizione in poi scorrono di un posto verso destra. insert(0, x) inserisce in testa.

Python
l = [4, 7, 2]
l.extend([1, 2])
print(l)
l.insert(1, 99)
print(l)
l.insert(0, 5)
print(l)

Output

python
[4, 7, 2, 1, 2]
[4, 99, 7, 2, 1, 2]
[5, 4, 99, 7, 2, 1, 2]

5.4 Modificare la lista: riordinare

reverse() inverte l'ordine; sort() ordina in modo crescente, e con reverse=True in modo decrescente. Entrambi modificano la lista stessa.

Python
l = [4, 7, 2]
l.reverse()
print(l)
l.sort()
print(l)
l.sort(reverse=True)
print(l)

Output

python
[2, 7, 4]
[2, 4, 7]
[7, 4, 2]

Con le stringhe l'ordinamento è alfabetico secondo il codice dei caratteri: le lettere maiuscole vengono prima di tutte le minuscole (per questo "Mela" è la prima). Con key=len si ordina invece per lunghezza delle parole; a parità di lunghezza resta l'ordine di prima.

Python
parole = ["pera", "Mela", "kiwi", "banana"]
parole.sort()
print(parole)
parole.sort(key=len)
print(parole)

Output

python
['Mela', 'banana', 'kiwi', 'pera']
['Mela', 'kiwi', 'pera', 'banana']

6. Scorrere una lista

Una lista contiene dati perché prima o poi vogliamo fare qualcosa con ognuno: stamparli, sommarli, confrontarli. Per questo il ciclo for della lezione 3 e le liste vanno sempre insieme. Un for si legge quasi come una frase: "per ogni prodotto nella spesa, stampa Compra e il prodotto".

Python
spesa = ["pane", "latte", "uova"]
for prodotto in spesa:
    print("Compra:", prodotto)

Output

python
Compra: pane
Compra: latte
Compra: uova

Ad ogni giro la variabile prodotto assume il valore dell'elemento successivo, dal primo all'ultimo. Non c'è bisogno di contare né di usare gli indici: Python sa quando la lista finisce. Rispetto al C o a Java (dove si scrive for (int i = 0; i < n; i++) e poi v[i]) il codice è più corto e c'è meno rischio di errore sugli indici.

6.1 Quando serve anche la posizione

Ci sono casi in cui il valore non basta: per numerare gli elementi (1, 2, 3 ...), per modificarli (sezione 4.1) o per confrontare un elemento con il vicino. Si usa allora range(len(lista)), che produce proprio gli indici validi 0, 1, ..., len - 1, e si legge l'elemento con lista[i]:

Python
spesa = ["pane", "latte", "uova"]
for i in range(len(spesa)):
    print(i + 1, spesa[i])

Output

python
1 pane
2 latte
3 uova

Python offre una scorciatoia, enumerate, che a ogni giro fornisce due valori: la posizione e l'elemento. Il secondo argomento dice da quale numero cominciare a contare (qui 1, per una numerazione "umana"). I due programmi seguenti producono lo stesso output:

Python
spesa = ["pane", "latte", "uova"]
for i, prodotto in enumerate(spesa, 1):
    print(i, prodotto)

Output

python
1 pane
2 latte
3 uova
🧭
Quale ciclo scelgo?

for elemento in lista: serve solo il valore (somme, ricerche, stampe, conteggi).

for i in range(len(lista)) o enumerate: serve la posizione (modificare gli elementi, numerare, confrontare vicini).

Una regola pratica: se nel corpo del ciclo scrivi lista[i] solo per leggere, probabilmente basta il primo.

7. Schemi di programmazione con le liste

Quasi tutti i problemi sulle liste si risolvono con pochi schemi, cioè piccoli programmi tipo che si adattano ogni volta. Imparali bene: ritorneranno nei cicli, nelle funzioni e in NumPy e pandas. Per ognuno trovi l'idea, il codice e, dove serve, una traccia che mostra come cambiano le variabili ad ogni giro.

7.1 Somma e media: l'accumulatore

Si parte da una variabile a 0 (l'accumulatore) e ad ogni giro si aggiunge l'elemento corrente. È la stessa idea del totale dello scontrino alla cassa: si passa un prodotto alla volta e il totale cresce. Qui la stampa dentro il ciclo mostra la crescita:

Python
voti = [6, 4, 8]
totale = 0
for v in voti:
    totale += v
    print("v =", v, " totale =", totale)
print("Media:", totale / len(voti))

Output

python

v = 4  totale = 10
v = 8  totale = 18
Media: 6.0

Questo schema è così comune che Python lo offre già pronto: sum(voti) / len(voti) dà lo stesso risultato in una riga, ed è quello che si usa nel codice vero. Ma capire il ciclo serve per quando la somma ha una condizione (somma dei soli pari, dei soli sufficienti ...).

Python
voti = [6, 8, 7, 9]
media = sum(voti) / len(voti)
print(f"Media: {media:.2f}")

7.2 Costruire una lista: lista vuota + append

Quando i valori non sono già in una lista ma si producono con un ciclo, si crea prima una lista vuota, poi nel ciclo si aggiunge ogni valore con append. Ricorda: la lista vuota va creata prima del ciclo (se la crei dentro, viene azzerata ad ogni giro).

Python
quadrati = []
for n in range(1, 6):
    quadrati.append(n * n)
print(quadrati)

Output

python
[1, 4, 9, 16, 25]

7.3 Filtro: aggiungere solo se la condizione è vera

È lo schema precedente con un if davanti all'append: si scorre una sequenza e si tengono solo gli elementi che soddisfano la condizione. Si legge: "per ogni numero, se è pari, aggiungilo alla lista dei pari".

Python
pari = []
for n in range(1, 11):
    if n % 2 == 0:
        pari.append(n)
print(pari)

Output

python
[2, 4, 6, 8, 10]

7.4 Massimo e minimo "a mano"

Idea: tieni in una variabile il migliore finora. Parti dal primo elemento e ad ogni giro confronti l'elemento corrente con il migliore: se è più piccolo (o più grande) lo sostituisci. Alla fine la variabile contiene il risultato. Ecco la traccia per il minimo di [6, 4, 8, 5]:

Python
voti = [6, 4, 8, 5]
minimo = voti[0]
for v in voti:
    if v < minimo:
        minimo = v
    print("v =", v, " minimo =", minimo)

Output

python
v = 6  minimo = 6
v = 4  minimo = 4
v = 8  minimo = 4
v = 5  minimo = 4

Esistono già min e max, ma lo schema è importante: lo useremo per trovare, ad esempio, "la parola più lunga" o "lo studente con il voto più alto", dove max da solo non basta. Perché si parte dal primo elemento e non da 0? Perché se tutti i voti fossero positivi e si partisse da 0, il minimo risulterebbe 0, che non è nella lista!

Python
voti = [6, 4, 8, 5, 9]
massimo = voti[0]
for v in voti:
    if v > massimo:
        massimo = v
print("Massimo:", massimo)

Output

python
Massimo: 9

7.5 Conteggio e ricerca

Conteggio: un contatore a 0 che sale di 1 ogni volta che la condizione è vera. Ricerca: una variabile booleana (qui trovato) che parte da False e diventa True se si incontra l'elemento cercato. Per una ricerca semplice basta l'operatore in (secondo esempio); il ciclo serve quando devi fare altro oltre a cercare.

Python
voti = [6, 4, 8, 5, 9]
insufficienti = 0
for v in voti:
    if v < 6:
        insufficienti += 1
print("Insufficienti:", insufficienti)
print("C'è un 9?", 9 in voti)

Output

python
Insufficienti: 2
C'è un 9? True

La stessa ricerca scritta con il ciclo e la variabile booleana (con l'espressione condizionale della lezione 2 per stampare il messaggio):

Python
nomi = ["Anna", "Luca", "Sara"]
ricerca = "Luca"
trovato = False
for n in nomi:
    if n == ricerca:
        trovato = True
print("Trovato" if trovato else "Non trovato")

Output

python
Trovato

7.6 Per chi vuole di più: list comprehension

I due schemi 7.2 e 7.3 si possono scrivere in una sola riga, con una forma tipica di Python detta list comprehension. Si legge quasi come in matematica, "{ n² per n da 1 a 5 }". Il risultato è identico a quello dei cicli; non è obbligatoria, ma la incontrerai spesso nel codice altrui.

Python
quadrati = [n * n for n in range(1, 6)]

8. Dividere e unire: split e join

Spesso i dati arrivano come un unico testo (una riga digitata, una riga di un file) ma ci servono separati. testo.split() taglia la stringa in corrispondenza degli spazi e restituisce la lista delle parti. separatore.join(lista) fa l'operazione opposta: incolla gli elementi di una lista (che devono essere stringhe) mettendo il separatore tra uno e l'altro.

Python
frase = "il gatto dorme"
parole = frase.split()
print(parole)
print(len(parole))
print("-".join(parole))

Output

python
['il', 'gatto', 'dorme']
3
il-gatto-dorme

Senza argomenti split() divide sugli spazi (anche più spazi di fila e anche a capo). Con un argomento, divide su quel carattere. Nota: due separatori consecutivi producono una stringa vuota; join funziona con qualsiasi separatore, anche vuoto.

Python
print("2026/10/26".split("/"))
print("a,b,,c".split(","))
print(", ".join(["rosso", "verde", "blu"]))
print("".join(["a", "b", "c"]))

Output

python
['2026', '10', '26']
['a', 'b', '', 'c']
rosso, verde, blu
abc

8.1 Leggere più numeri su una riga

Il caso d'uso più frequente: l'utente scrive "7 3 9 4" e vogliamo i numeri. Attenzione: split restituisce stringhe, che vanno convertite una a una con int() (o float()), altrimenti si ottiene un errore. Ecco i tre passaggi:

riga = "7 3 9 4"

10. Liste di liste (matrici)

Gli elementi di una lista possono essere a loro volta liste. Se ogni lista interna ha la stessa lunghezza si ottiene una tabella con righe e colonne, cioè una matrice. Pensa al registro di classe: ogni riga è uno studente e ogni colonna è un compito.

💡

Un'analogia: il condominioUn palazzo ha tanti piani, e su ogni piano tanti appartamenti. Per indicare un appartamento servono due numeri: il piano e il numero sulla porta. Una lista di liste funziona così: griglia[1][2] vuol dire "vai alla riga 1, poi prendi l'elemento in posizione 2". Il primo indice sceglie la riga (il piano), il secondo la colonna (la porta).

Python
griglia = [[1, 2, 3],
           [4, 5, 6]]
print(len(griglia))
print(len(griglia[0]))
print(griglia[0])
print(griglia[1][0])
griglia[0][2] = 30
print(griglia)

Output

python
2
3
[1, 2, 3]
4
[[1, 2, 30], [4, 5, 6]]

Nell'output: len(griglia) è 2 perché ci sono 2 righe (le liste interne); len(griglia[0]) è 3 perché la riga 0 ha 3 colonne; griglia[0] è l'intera prima riga; griglia[1][0] è il primo elemento della seconda riga; infine griglia[0][2] = 30 modifica un elemento singolo.

10.1 Percorrere una matrice

Servono due cicli annidati (lezione 3): il ciclo esterno prende una riga per volta, quello interno percorre i valori di quella riga. Un solo ciclo basta per stampare una riga alla volta:

Python
griglia = [[1, 2, 3],
           [4, 5, 6]]
print(griglia[1][2])
for riga in griglia:
    print(riga)

Output

python
6
[1, 2, 3]
[4, 5, 6]

Per toccare ogni singolo valore (qui per sommarli tutti) serve anche il ciclo interno; senza di esso riga sarebbe una lista e la somma darebbe errore.

Python
griglia = [[1, 2, 3],
           [4, 5, 6]]
totale = 0
for riga in griglia:
    for valore in riga:
        totale += valore
print(totale)

Output

python
21

11. Attenzione: assegnare non vuol dire copiare

Questa è la parte più insidiosa delle liste. Nella lezione 1 abbiamo detto che le variabili sono etichette attaccate ai valori. Per i numeri e le stringhe non ci accorgiamo della differenza, perché non si possono modificare. Con le liste, che si possono modificare, la differenza si vede.

💡

Un'analogia: il documento condivisoSe condividi un documento online con un amico, non ne fai una fotocopia: voi due avete due link allo stesso file. Se lui cambia una riga, la vedi cambiata anche tu. In Python b = a funziona così: non crea una nuova lista, ma attacca una seconda etichetta alla stessa lista.

Python
a = [1, 2, 3]
b = a
b.append(4)
print(a)

Output

python
[1, 2, 3, 4]

Abbiamo modificato la lista tramite b, ma a è cambiata: sono due nomi dello stesso oggetto. Si può verificare con l'operatore is ("è lo stesso oggetto?"), da non confondere con == ("hanno lo stesso contenuto?"):

Python
a = [1, 2, 3]
b = a
print(a is b)
c = a.copy()
print(a is c)
print(a == c)

Output

python
True
False
True

Se invece vogliamo una fotocopia indipendente, usiamo .copy() (oppure la fetta a[:]). Da quel momento le due liste sono separate:

Python
a = [1, 2, 3]
c = a.copy()
c.append(5)
print(a)
print(c)

Output

python
[1, 2, 3]
[1, 2, 3, 5]

Perché con i numeri e le stringhe non succede? Perché non si possono modificare: se scrivi altro = "Luca" non cambi la stringa, sposti l'etichetta su un nuovo valore, e l'altra etichetta resta dov'era:

Python
nome = "Anna"
altro = nome
altro = "Luca"
print(nome)

Output

python
Anna

In C/Java succede qualcosa di simile con puntatori e riferimenti agli array: b = a copia il riferimento, non il contenuto.

12. Errori frequenti

Questi errori capitano a tutti. Il messaggio di Python dice di che errore si tratta e in quale riga: leggilo con attenzione prima di cambiare il codice.

ErroreMessaggio
Indice fuori dalla listaIndexError: list index out of range
Rimuovere un valore assenteValueError: list.remove(x): x not in list
Massimo di una lista vuotaValueError: max() iterable argument is empty
Sommare stringhe (dopo split senza int)TypeError: unsupported operand type(s) for +: 'int' and 'str'
Cambiare una lettera di una stringaTypeError: 'str' object does not support item assignment

Gli errori più subdoli sono quelli che non danno nessun messaggio ma producono un risultato sbagliato:

  • lista = lista.append(x) e l2 = l.sort(): la variabile diventa None. Si chiamano i metodi senza assegnare il risultato.
  • b = a credendo di copiare: le modifiche si vedono in entrambe. Serve a.copy().
  • Indice uguale a len(lista): l'ultimo indice valido è len(lista) - 1 (IndexError).
  • Modificare una lista mentre la si scorre con for (aggiungere o togliere elementi): porta a risultati inattesi; meglio costruire una lista nuova.
  • Assegnare alla variabile del ciclo (for v in voti: v = v + 1) pensando di modificare la lista: serve l'indice.
  • Creare la lista vuota dentro il ciclo invece che prima: viene azzerata ad ogni giro.

13. Riepilogo

  • Una lista contiene più valori, anche di tipi diversi: [1, "a", 2.5]. Gli indici partono da 0, [-1] è l'ultimo, le fette [inizio:fine] escludono la fine.
  • Le liste sono mutabili: l[i] = x, append, insert, extend, remove, pop, del, sort, reverse. Le stringhe no.
  • Per leggere: len, sum, min, max, sorted, count, index, in.
  • I metodi che modificano non restituiscono nulla (None): non vanno assegnati.
  • Si scorrono con for x in l (serve il valore), range(len(l)) o enumerate (serve la posizione).
  • Schemi: accumulatore, costruzione con append, filtro, massimo/minimo, conteggio, ricerca.
  • split e join passano da stringhe a liste e viceversa; dopo split ricordati di convertire con int/float.
  • Una matrice è una lista di liste: m[riga][colonna], con due cicli annidati e una lista nuova per ogni riga.
  • b = a non copia: due nomi per la stessa lista; serve a.copy().
