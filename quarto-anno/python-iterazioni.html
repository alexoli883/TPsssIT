1. Dalla scelta alla ripetizione

Con le istruzioni condizionali un programma può scegliere cosa fare. Spesso però serve anche ripetere un blocco di istruzioni: stampare una tabellina, sommare cento numeri, richiedere un dato finché non è valido. Scrivere la stessa istruzione cento volte sarebbe impensabile: per questo esistono le iterazioni (o cicli), che ripetono un blocco di istruzioni finché serve.

Python ha due tipi di ciclo:

  • while: ripete finché una condizione resta vera. Si usa quando non si sa in anticipo quante volte servirà (per esempio, finché l'utente non scrive la risposta giusta).
  • for: ripete per ogni elemento di una sequenza, ad esempio per ogni numero di un intervallo o per ogni lettera di una stringa. Si usa quando si sa già quante volte ripetere.

2. Il ciclo while

💡

Un'analogia: la salsa sul fuocoUn cuoco prepara una salsa e segue questa regola: "finché la salsa non si è addensata, continua a mescolare". Prima di ogni giro di cucchiaio controlla la salsa: se è ancora liquida mescola ancora, se è già densa smette. Se la salsa è densa fin dall'inizio, non mescola nemmeno una volta. Il ciclo while funziona così: controlla la condizione prima di ogni giro.

Sintassi

Python
while condizione:
    istruzioni da ripetere
Python
contatore = 1
while contatore <= 5:
    print("Giro numero", contatore)
    contatore += 1
print("Fine")

Output

python
Giro numero 1
Giro numero 2
Giro numero 3
Giro numero 4
Giro numero 5
Fine
  • Come per if, dopo la condizione ci sono i due punti e il blocco da ripetere è indentato (4 spazi).
  • La condizione si controlla all'inizio di ogni giro. Se è falsa fin dal primo controllo, il blocco non viene eseguito nemmeno una volta.
  • Dentro il blocco deve cambiare qualcosa (qui contatore += 1) che, prima o poi, renda falsa la condizione.
♾️
Il ciclo infinito

Se la condizione non diventa mai falsa, il ciclo non finisce più e il programma si blocca. È l'errore più tipico del while:

Python
contatore = 1
while contatore <= 5:
    print("Giro numero", contatore)
    # manca contatore += 1: la condizione resta sempre vera!

Per fermare un programma bloccato usa il pulsante Stop dell'editor oppure Ctrl+C nel terminale.

Ripetere finché l'utente non dice basta

Un valore speciale che segnala la fine dell'inserimento si chiama sentinella. Qui è lo 0: serve a terminare e non fa parte dei dati. Si legge il primo valore prima del ciclo e poi si rilegge alla fine di ogni giro.

Python
somma = 0
n = int(input("Numero (0 per finire): "))
while n != 0:
    somma += n
    n = int(input("Numero (0 per finire): "))
print("Somma:", somma)

Esempio di esecuzione

Numero (0 per finire): 5
Numero (0 per finire): 4
Numero (0 per finire): 0
Somma: 12

Controllare l'input

Con while si può ripetere una domanda finché la risposta non è valida. La condizione descrive il caso in cui la risposta non va bene.

Python
password = input("Password: ")
while password != "python":
    print("Password errata")
    password = input("Password: ")
print("Accesso consentito")

Cercare un valore

Quando non si sa quanti giri serviranno, il while è la scelta naturale. Qui si cerca il primo multiplo di 7 maggiore di 50:

Python
n = 51
while n % 7 != 0:
    n += 1
print("Primo multiplo di 7 dopo 50:", n)

Output

python
Primo multiplo di 7 dopo 50: 56
🔁

Il do-while non esiste in PythonIn C e Java esiste il ciclo do { ... } while (condizione); che esegue il blocco almeno una volta prima di controllare. In Python non c'è: si ottiene lo stesso effetto con while True: e break (vedi la sezione 5).

3. Il ciclo for e la funzione range

💡

Un'analogia: salire una scalaSe sai già che una scala ha 5 gradini, non ti chiedi "ho finito?" a ogni passo: li percorri uno per uno, dal primo all'ultimo. Il for fa lo stesso: prende uno alla volta gli elementi di una sequenza e per ognuno esegue il blocco. range costruisce la sequenza di numeri da percorrere.

Sintassi

Python
for variabile in sequenza:
    istruzioni da ripetere
Python
for i in range(5):
    print(i, end=" ")

Output

python
0 1 2 3 4

La funzione range genera una sequenza di numeri interi. Ha tre forme:

  • range(fine): da 0 fino a fine - 1.
  • range(inizio, fine): da inizio fino a fine - 1.
  • range(inizio, fine, passo): da inizio, aumentando di passo finché si resta prima di fine. Con un passo negativo si conta all'indietro.

range(0, 10, 3)0 3 6 94
range(10, 0, -2)10 8 6 4 25
range(5, 5)(nessun valore)0

Il for scorre anche le stringhe

Una stringa è una sequenza di caratteri, quindi il for può percorrerla una lettera alla volta, senza indici:

Python
parola = "ciao"
for lettera in parola:
    print(lettera.upper(), end="-")
print()

Output

python
C-I-A-O-

Combinato con if e con l'operatore in permette di contare le lettere con una certa proprietà:

Python
frase = "informatica"
vocali = 0
for lettera in frase:
    if lettera in "aeiou":
        vocali += 1
print("Vocali:", vocali)

Output

python
Vocali: 5
⚠️
Per chi viene da C: la variabile del for non si controlla

In Python il for prende i valori dalla sequenza, non da un contatore che si aggiorna: cambiare i dentro il ciclo non influisce sul giro successivo.

Python
for i in range(3):
    i += 10
    print(i)

Output (il ciclo gira comunque 3 volte)

python
10
11
12
⚠️
La variabile del ciclo esiste anche dopo

A differenza del C, la variabile del ciclo esiste ancora dopo il ciclo e conserva l'ultimo valore assunto:

Python
for i in range(3):
    pass
print(i)

Output

python
2

4. Schemi ricorrenti

La maggior parte dei programmi con i cicli riusa pochi schemi. Riconoscerli ti farà risparmiare molto tempo.

📌

Due analogie per ricordarliIl contatore è come il tornello di un museo: a ogni persona che passa, il numero sale di 1. L'accumulatore è come un salvadanaio: a ogni giro ci metti dentro qualcosa e, alla fine, guardi quanto contiene. Entrambi si azzerano una volta sola, prima di iniziare.

SchemaA che cosa serveCome si scrive
ContatoreContare quante volte accade qualcosaconta = 0 prima del ciclo; conta += 1 nel ciclo
AccumulatoreSommare (o moltiplicare) valorisomma = 0 prima del ciclo; somma += valore nel ciclo
Massimo / minimoTrovare il valore più grande o più piccoloSi parte dal primo valore letto, non da 0; poi if n > maggiore: maggiore = n
SentinellaTerminare un inserimento di lunghezza ignotaValore speciale che ferma il while
ValidazionePretendere un dato correttowhile che ripete la domanda finché non è valido

Ecco l'accumulatore in azione. Ad ogni giro stampiamo i valori per seguire come cambiano le variabili (una "traccia" del programma):

Python
totale = 0
for i in range(1, 5):
    totale += i
    print("i =", i, " totale =", totale)

Output

python
i = 1  totale = 1
i = 2  totale = 3
i = 3  totale = 6
i = 4  totale = 10
⚠️

Partire da 0 non va sempre benePer cercare il massimo non si inizializza la variabile a 0: se tutti i numeri sono negativi, il risultato sarebbe sbagliato (0 non fa parte dei dati). Si parte dal primo valore letto.

5. break e continue

  • break interrompe subito il ciclo e prosegue con l'istruzione che lo segue.
  • continue salta il resto del giro corrente e passa al giro successivo (ricontrollando la condizione, nel while).
Python
for i in range(1, 11):
    if i == 4:
        continue
    if i == 8:
        break
    print(i, end=" ")

Output

python
1 2 3 5 6 7

Il giro con i == 4 viene saltato; con i == 8 il ciclo termina e il 9 e il 10 non vengono mai raggiunti.

break e continue, un giro alla volta

python
pronto

while True con break

Questo schema serve quando devi fare qualcosa prima di poter decidere se continuare. Esempio: per sapere se un numero va bene devi prima leggerlo. Con un while normale sei costretto a scrivere la lettura due volte, una prima del ciclo e una alla fine di ogni giro:

Python
n = int(input("Numero positivo: "))
while n <= 0:
    print("Non è positivo, riprova")
    n = int(input("Numero positivo: "))
print("Hai scelto", n)

La riga con input compare due volte: basta dimenticarne una o modificarne una sola per introdurre un errore. Con while True la lettura si scrive una volta sola e si decide di uscire dall'interno del ciclo, quando il dato è già in mano.

💡

Un'analogia: la giostra con il pulsante di stopwhile True significa "gira sempre": è una giostra che, da sola, non si fermerebbe mai. Il break è il pulsante di stop che il controllore preme da dentro, nel momento in cui vede che è giusto fermarsi (di solito dentro un if). Una giostra senza pulsante gira all'infinito: un while True senza break è un ciclo infinito.

Ecco lo stesso programma con ogni riga numerata e commentata. Segui i numeri:

Python
while True:                              # 1. sempre vera: il ciclo parte
    n = int(input("Numero positivo: "))  # 2. leggo il numero
    if n > 0:                            # 3. va bene?
        break                            # 4. sì: esco dal ciclo
    print("Non è positivo, riprova")     # 5. no: avviso e si torna in cima
print("Hai scelto", n)                   # 6. qui si arriva dopo il break

Che cosa succede se l'utente scrive -4, poi 0, poi 6:

GiroNumero letton > 0 ?Che cosa succede

20NoCome nel giro 1
36Sìbreak: si esce subito dal ciclo. La riga 5 non viene eseguita e si prosegue con la riga 6: "Hai scelto 6"

Da ricordare

1. while True: ha una condizione sempre vera: il ciclo, da solo, non finisce mai.

2. L'uscita è il break, di solito dentro un if. Quando viene eseguito, Python salta subito alla prima riga dopo il ciclo: le righe che restavano nel giro vengono ignorate. Per questo non serve un else (la riga 5 viene raggiunta soltanto se il break non è scattato).

3. Controlla sempre che il break sia raggiungibile: se la condizione dell'if non diventa mai vera, il ciclo è infinito.

while con condizionewhile True + break
Dove si decide di fermarsiIn cima al ciclo, nella condizioneDentro il ciclo, con if + break
Istruzioni da ripetereLa lettura va scritta due volteLa lettura è scritta una volta sola
Quando convieneLa condizione è semplice e si conosce già all'inizioIl dato serve prima di poter decidere (es. input da controllare)

Le due versioni sono equivalenti: scegli quella che rende il programma più leggibile.

6. Cicli annidati

Un ciclo può contenere un altro ciclo. Per ogni giro del ciclo esterno il ciclo interno viene eseguito per intero. Il numero totale di giri è il prodotto dei due: qui 3 righe × 4 colonne = 12 stampe.

Python
for riga in range(1, 4):
    for colonna in range(1, 5):
        print(riga * colonna, end=" ")
    print()

Output

python
1 2 3 4
2 4 6 8
3 6 9 12

Il print() vuoto, nel ciclo esterno, serve ad andare a capo alla fine di ogni riga. Con questo schema si disegnano figure con i caratteri:

Python
for riga in range(3):
    for colonna in range(5):
        print("*", end="")
    print()

Output

python
*****
*****
*****

Se la lunghezza della riga dipende dal valore del ciclo esterno (come nel triangolo di asterischi), il ciclo interno usa quel valore nel suo range.

Ogni for può essere riscritto con un while (con un contatore da inizializzare e aggiornare), ma non il contrario: il for è più sicuro perché non può dimenticare l'aggiornamento.

Come si collauda un cicloProva sempre tre casi: zero giri (il ciclo non parte), un solo giro e molti giri. Se il programma gestisce bene tutti e tre, quasi sicuramente funziona.

9. Riepilogo

  • while condizione: ripete finché la condizione è vera e la controlla prima di ogni giro; il blocco deve far cambiare la condizione, altrimenti il ciclo è infinito.
  • for variabile in sequenza: ripete per ogni elemento; range(inizio, fine, passo) genera numeri con l'estremo finale escluso.
  • Schemi ricorrenti: contatore, accumulatore (si azzerano prima del ciclo), massimo, sentinella, validazione.
  • break esce dal ciclo; continue salta al giro successivo; while True + break sostituisce il do-while.
  • Nei cicli annidati il ciclo interno viene eseguito per intero a ogni giro del ciclo esterno.
  • Collauda sempre con zero giri, un giro e molti giri.
